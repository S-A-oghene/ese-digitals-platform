# LinkedIn Distribution Version

I have been thinking about the difference between finding jobs and finding the right opportunities. A vacancy can say “remote” and still exclude a country. A search result can be stale. Multiple sites can show the same role.

That led me from better search queries toward opportunity intelligence: discovery + verification + eligibility + freshness + relevance + prioritisation.

The idea is simple: the query should be the beginning of the process, not the product itself.
